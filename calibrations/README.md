# calibrations/

One directory per cell. Committed on purpose.

```
calibrations/
└── purdue-ur5e-01/
    ├── extrinsics.yaml              <- what the `cell` profile reads at boot
    ├── extrinsics.2026-08-14.bak.yaml
    └── 2026-08-14_ur5e_d435_eob.calib   <- raw easy_handeye2 output, archived
```

`extrinsics.yaml` is generated by `scripts/promote_calibration.py`, never by
hand. It is the single source of truth for the cell's static geometry, read by
`cell_description` for TF and directly parseable by the ZMQ sidecars without
pulling in ROS.

**Why this is version controlled.** A calibration is an experimental result. Six
months from now, when a grasp is consistently 8 mm off, the question you will
need to answer is "which calibration was this run using, and what changed" —
and the only way to answer it is if every result was kept, date-stamped, next
to the raw `.calib` that produced it.

Promoting a new result archives the previous `extrinsics.yaml` automatically,
so reverting a calibration that turned out worse than the old one is a `git
checkout` or a file copy, not an afternoon.
